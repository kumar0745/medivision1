# Interactive demo mode

## Entry
From the sign-in screen, choose **Explore interactive demo**. No email, password or registration is needed.

## Sample data included
The first demo session includes clearly fictional examples:
- Three wellness check-ins with mood, sleep, note and an illustrative stress index.
- Three health-note examples with a record category and general, non-diagnostic note.
- Two cycle-log examples with explicitly fictional dates.
- One example emergency contact with a dummy telephone number.

All entries demonstrate the interface only. They are not medical histories or real emergency contacts.

## Interactions to try
1. Overview — review sample counts, recent notes and navigation cards.
2. Health check — use an example description, change the entry category, and save a sample note.
3. Wellness — choose a mood, enter sleep hours, add a note and save a check-in.
4. Age guidance — step through the general age-group routine checklist.
5. Women's health — add a fictional date and optional note, then open the awareness tab.
6. Emergency — add an example contact, remove it, open the preparedness checklist and download a text safety card.
7. AI assistant — choose a prompt or ask about sleep, stress, exercise, cycle awareness or emergency warning signs. Demo responses are scripted examples with public reference links where relevant.
8. My records — review entries and download a demo-labelled wellness summary.
9. Profile — change the demo display name, age group or goals.

## Data behaviour
- Browser-local storage key: `mv_demo_data_v2`.
- Demo profile key: `mv_demo_user`.
- Demo session indicator: `mv_demo`.
- Entries remain in the current browser only and are not sent to the FastAPI backend.
- Use **Reset demo data** in the sidebar to restore the original sample set.
- Use **Exit demo** to return to the sign-in screen.

Do not enter real patient data, actual medical reports, private contact details or sensitive information. This is not a diagnosis system.
